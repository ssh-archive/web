# 작가 포트폴리오

별도 설치 없이 브라우저에서 열어볼 수 있는 작은 정적 사이트입니다. VS Code에서 이 폴더를 열고 파일을 수정하세요.

화면은 흰 바탕과 얇은 검은 구분선으로 구성했습니다. 첫 화면은 가운데 정렬한 상단 인덱스, 16:9 비율의 메인 슬라이드, 넉넉한 여백 뒤 5열 작업 그리드로 이어집니다. 그리드 타일은 얇은 선 대신 바탕이 살짝 보이는 4px 간격으로 나뉩니다. 메인 슬라이드는 10초마다 다음 작업으로 바뀌며, 클릭하면 즉시 다음 작업으로 넘어가고 10초 타이머가 다시 시작됩니다. 홈페이지에는 작업 15개가 보이고, 작품 데이터에는 예시 25개가 들어 있습니다. 전체 글꼴은 Helvetica 계열 산세리프입니다.

작품 목록은 제목과 기본 캡션을 한 줄로 표시합니다. 작품 상세 화면에서도 왼쪽 제목 목록은 첫 화면과 같은 20% 너비를 사용합니다. 목록·아카이브·상세 캡션의 공통 글자 크기는 `styles.css` 맨 위의 `--label-size` 한 곳에서 바꿀 수 있습니다.

## 시작하기

`index.html`을 브라우저에서 열면 됩니다. VS Code의 Live Server 확장 프로그램이 이미 있다면 `index.html`에서 **Open with Live Server**를 선택해도 됩니다.

## 내 작품으로 바꾸기

1. `works.js`를 열고 `artistInfo`의 작가명, 소개글, 이메일, 인스타그램 주소를 수정합니다.
2. `window.works` 배열에서 각 작품의 제목, 연도, 형식, 역할, 설명을 수정합니다.
3. 파일 목록의 매체와 크기는 각 작품 객체의 `medium`과 `size` 값에서 읽습니다. 아카이브 열은 `archiveMaterial`, `size`, `timeline` 값에서 읽으므로 각 항목을 직접 바꾸면 됩니다.
4. 이미지 파일은 `assets` 폴더에 넣습니다. `poster: "assets/파일명.jpg"`를 지정하면 메인 슬라이드·그리드와 작품 페이지의 영상 대기 화면에 사용됩니다. `homeImage: "assets/파일명.jpg"`는 홈페이지 슬라이드와 그리드에만 표시합니다. 비디오가 아닌 작품 상세에도 같은 이미지를 보이게 하려면 `poster`도 지정하세요. 홈페이지 표시 개수는 `app.js`의 `works.slice(0, 15)`에서 바꿀 수 있습니다. 슬라이드 주기는 `app.js`의 `setTimeout` 값(현재 10000ms)에서 바꿀 수 있습니다.
5. `video`에 YouTube·Vimeo 주소 또는 mp4 경로를 넣으면 작품 페이지에서 영상이 재생됩니다. 비워두면 영상 플레이어만 표시됩니다.
6. 작품 상세의 오른쪽 이미지 칸에는 `materials: ["assets/detail-01.jpg", "assets/detail-02.jpg"]`처럼 최대 네 장을 추가할 수 있습니다. 상세 화면은 스크롤 없이 고정됩니다.

작품 카드를 추가할 때는 `works.js`의 객체를 복사하고, `slug` 값은 작품마다 다르게 지정하세요. 파일 구조와 화면 렌더링은 `app.js`, 색상·레이아웃은 `styles.css`에서 수정할 수 있습니다.

작품 상세 화면은 스크롤되지 않으며, 왼쪽에 작품 제목 목록, 가운데에 메인 영상 또는 이미지, 오른쪽에 캡션과 최대 네 장의 추가 이미지를 배치합니다. `ARCHIVE` 페이지에는 제목과 캡션을 크게 표시하며, 항목에 커서를 올리면 전체 너비의 얇은 밑줄이 나타납니다.

## 파일 안내

- `index.html`: 사이트 기본 뼈대
- `works.js`: 작가 소개와 작품별 콘텐츠
- `app.js`: 작품 목록, 작품 상세, Info 화면 렌더링
- `styles.css`: 반응형 레이아웃과 시각 스타일
